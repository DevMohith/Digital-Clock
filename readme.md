This is a digital clock web project built using HTML, CSS, and Vanilla JavaScript. It displays the current time in hours, minutes, and seconds, and also shows the current day and date with a smooth scrolling animation. The time and date are retrieved using JavaScript’s built-in Date object, which accesses the user's local system time without relying on any external APIs. The methods like getHours(), getMinutes(), getSeconds(), getDay(), getDate(), and getFullYear() are used to extract specific parts of the current time and date. This project works entirely offline, is responsive, and has a clean modern design suitable for deployment and public use.

Tech Stack:
Html, CSS, Vanilla Javascript, javacripts builtin objects
